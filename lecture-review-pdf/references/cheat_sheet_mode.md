# Cheat：A4 考试参考表

## 页面契约

- A4 210 × 297 mm；方向遵循已确定的 portrait/landscape。
- 单面恰好 1 页；双面恰好 2 页，前面在先、背面在后，每面必须有实际知识内容。只有页眉不算内容页。
- 黑/深灰字、白底、细分隔线、2 或 3 栏、紧凑标题。长公式要考虑栏宽，不能拆断变量造成含义变化。
- 字号使用用户选定的 profile 或更高的 `min_font_pt`；ultra 需明确选择。内置最小下限为 6.6 pt，不以降低字号或隐去内容掩盖超页。
- 页边距默认 3 mm，可在 2–12 mm 内调整；优先扩大有效内容区。已知打印机非打印区域时遵守它，不把文字放到纸外；软件边界检查不构成硬件验证。
- 打印页只包含考试有用的信息：概念、公式、条件、变量、步骤、易错点和有迁移价值的算例。省去来源栏、原文件名、原页码、仅用于定位的讲次/作业题号、制作说明、通用免责声明、装饰性总标题与页码。简短知识点标题用于检索，可以保留。
- `source_name`、`source_pages` 仍须准确填写在编写 JSON 中，用于核验与追溯，不占打印页空间。不要把这些信息重新写进 `heading` 或 `cheat_text`。

## 编辑原则

按照用户确定的范围和优先级，优先保留定义、公式、变量/单位、阈值、条件和容易混淆的区别。可压缩重复解释，不能把相关性改写为因果、把限定条件删成无条件结论，或从风格示例借用课程事实。

每个 `concept_entries` 都需要明确编写 `cheat_text`；渲染器不会从 `details` 自动截断。`formula` 若没有原样包含在 `cheat_text` 中，会额外显示，编写时检查重复是否有必要。不在打印页显示的讲解背景不能替代对压缩文字的准确性检查。

## 公式与留白

- 多个短公式能在当前栏宽内清晰排下时，合为同一数学行，以逗号、分号或适量 `\quad` 分隔，不为每个公式单独起一整行。先按语义组织再排版，不依靠缩放或删除条件来塞入。
- 相关公式可集中成紧凑公式组，手工编号如 `(F1)`、`(F2)`，正文用“由 F1”引用，避免在解释中重复插入整块公式。编号要唯一、引用可找到，只有确实节省空间或便于查找时才使用。
- 正文中的短公式优先 `$...$`，不额外插入空段落；不强制 `\displaystyle` 把简单行内分式撑高。独立公式与前后文字的间距尽量小：模板上下默认 1.5 pt，短行前后 0.5 pt，段距 0.5 pt，多行公式额外行距 1 pt。高矩阵、积分、上下标仍须留足实际字形高度，不能重叠。
- 避免用垂直拉伸把各栏硬撑齐底；栏末可自然留白。应通过合并短公式、调整条目/分栏和增加有用内容提高容量，而不是扩大公式上下空白。小标题须随至少一行正文，矩阵与不可分的公式组不要跨栏切开。
- 同行示例：`$$\text{(F1)}\ T_s=1/f_s,\quad\omega=2\pi f/f_s\qquad\text{(F2)}\ f_N=f_s/2$$`。这只是排版示例；实际内容仍来自当前课程。过宽时按完整公式分行，复杂组可用 `aligned`，不要缩小字号。

`page: 1|2` 表示已明确的正/背面安排。未指定时按内容权重自动分配；权重不是实际排版高度，失败后可以在用户授权的版式范围内重新安排，但要保留顺序关系与来源。单面不能指定 page 2；双面不能把所有条目固定到同一面。

## 验收和容量不足

生成成功仅代表自动检查满足约束。使用同一份 JSON 检查最终 PDF，再逐页渲染查看：字号、公式、汉字、标题、栏间和页边是否重叠或被裁切；核对公式周围无不必要的大空白、没有残留来源或制作信息。按源材料核对每个压缩条目，并检查编号引用、同排公式分隔、条件与变量，确认无意外删漏、符号替换或错误引用。

若失败，报告尝试过的字号与排版条件，不宣称证明了理论最少页数。提出具体压缩内容、改方向/栏数、单面改双面等选择；在已经授权的范围内可继续调整，需要改变硬约束时先获得选择。

交付注明 A4、方向、页数、实测字号、覆盖和经同意的删减；打印选“实际大小/100%”，双面提示核对翻转边。屏幕检查不能保证真实打印机或每个人的阅读舒适度；实际打印未执行就如实说明。
