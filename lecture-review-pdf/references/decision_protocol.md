# 选择协议

只解决实质歧义，遵循用户已经给出的范围、格式和授权。先从本次请求与当前对话提取已确定项；不能因为缺少某个 JSON 字段就重复问用户。

## 生成前需要确定

- 课程编码：沿用用户已确认的编码；若材料中无法明确确定，在生成前的询问环节向用户提问。禁止根据模糊文件名猜测，也不能省略文件名中的课程编码。确认 Skills 仓库位置后，生成文件放在 `output/lecture-review-pdf/<课程编码>/`；仓库位置不明确时一并询问。
- 模式：复习资料还是固定页面的 cheat sheet。用户已经说“复习大纲”或“一张双面小抄”时无需再选模式。
- 来源与范围：使用哪些文件、章节和顺序。单文件不询问“合并或分开”；多文件的输出组织若不明确且有实际影响，再问。
- 语言：中文、英文或中文解释配英文术语。当前课程术语应保留原文。双语并排不属于内置渲染器的现成功能，若用户要求需单独实现并验证。
- summary：合并/逐份，以及详细复习/精简提纲；若用户已明确用途和深度则沿用。
- cheat：单面/双面、方向、范围、字号/密度和可影响容量的栏数。未确定的重要选项一次集中询问，避免反复打断。

例如，仅缺 cheat 的方向和密度时，给出竖版/横版，以及 comfortable（8.2–9.0 pt）、dense（7.2–8.2 pt）、ultra（6.6–7.2 pt）的清晰选择，说明它们的可读性差异。ultra 需要用户明确选择。若用户授权“你决定版式”，可在授权范围内选择并说明；不得据此删除未授权删减的章节。

具体字号边界以 `scripts/build_pdf.py` 的 `PROFILES` 为执行来源。`min_font_pt` 可进一步提高所选 profile 的下限；不能低于 profile 下限。页边距默认 4.8 mm，允许 4–12 mm；已知打印机需要更大留白时遵守硬件约束，超出内置支持范围需调整实现。无需每次询问临时文件名、配色、解释器或缓存。

## 压缩和中途分歧

“做精简复习/cheat sheet”已授权合并重复表达、缩短措辞和按明确范围总结，不应逐句请求批准。删除整个主题、改变用户指定重点、牺牲公式条件或越过字号下限属于实质变化，不能默许。

在容量不足时说明：当前范围、页数/方向/栏数/字号下限、失败结果；提出具体可删减主题或可改变版式。若有多种合理方案，列出各自损失和收益后等待选择。用户已经批准的优先级或删减清单可直接落实。

来源相互矛盾、关键页不可读、课件顺序会改变逻辑、未知考试限制会改变可用格式时，说明受影响部分并询问；继续整理其余已确定部分。不能因为一页有疑点就停止所有阅读，也不能用常识悄悄替换原课程结论。

## 验证不等同于偏好确认

用户选择版式后仍需自动检查和逐页视觉核对。150–250 dpi 图像只是检查材料；屏幕显示倍率和真实纸张尺寸可能不同。最终提供实际大小打印提示，明确是否做过真实打印。
