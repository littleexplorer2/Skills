# Skills

- [lecture-review-pdf](lecture-review-pdf/README.md)：有来源页码的课程复习 PDF。
- [email-draft](email-draft/README.md)：Windows / macOS 通用的中英文邮件撰写，三种礼貌风格，缺少语言或风格时先选择。

各 skill 的正式生成成果保存在 `output/<skill名称>/`。其中只有 PDF 复习笔记随仓库同步；导出的 skill ZIP 压缩包、其他生成格式和 `.tmp/` 临时文件不会上传。

正式 PDF 统一使用 `<标识>__<范围>__<类型>.pdf`；旧版放在所属区域的 `archive/`，文件名末尾加 `__rNN`，例如 `课程__范围__StudyGuide__r01.pdf`。各字段的具体含义由生成它的 skill 定义，详见对应 README。
